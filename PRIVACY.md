# Privacitat

El GPS es processa dins del dispositiu. Durant la conducció, un toc explícit a «Marca possible radar» guarda localment un punt GPS recent i precís com a esborrany; les posicions ordinàries no es desen. Cap coordenada no s'envia automàticament. No hi ha analítica, comptes d'usuari, anuncis ni servidor propi. La base inicial per a la major part d'Espanya s'inclou dins de l'app; les bases importades i les preferències es guarden a l'espai privat de l'app. Desinstal·lar l'app esborra aquestes dades segons el comportament del sistema.

L'única connexió de xarxa de l'app és la descàrrega de dades JSON des de la URL HTTPS de GitHub predeterminada o una URL HTTPS que l'usuari configure. Es pot iniciar manualment amb «Actualitza ara». L’actualització automàtica és optativa: es comprova en obrir l’app i periòdicament mentre continua oberta, com a màxim una vegada cada set dies després d’una descàrrega correcta. Pot fer una descàrrega durant la conducció; valida i guarda la nova base localment, però només l’activa en acabar el trajecte o si l’usuari prem el botó de confirmació. En confirmar, es reinicien els avisos i el flux GPS. La petició no inclou coordenades GPS. Obrir GitHub des de la pantalla de propostes no inclou coordenades en la URL; l'usuari decideix si copia la proposta i la publica en una incidència pública. Els esborranys es poden esborrar des de l'app. El servidor de la font pot veure la IP i la petició HTTP, però no rep coordenades GPS de l'app. A Android només se seleccionen veus TTS marcades pel sistema com a offline; si no n'hi ha, es fa servir únicament el so. A iOS la veu depèn del sistema operatiu i s'ha de validar en dispositiu abans de publicar.

Permisos Android: ubicació precisa mentre s'usa l'app, servei en primer pla i notificacions per mostrar que el GPS continua actiu. Internet només per a actualitzacions optatives. iOS: ubicació mentre s'usa l'app. No es demana ubicació permanent.
